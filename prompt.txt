Напиши готовое решение для подключения Roblox Studio к моей локальной базе данных MariaDB. 

Так как Roblox Studio не может напрямую работать с базами данных, мне нужен локальный веб-сервер (REST API) в качестве прослойки, который будет принимать HTTP-запросы от Roblox и выполнять запросы к MariaDB.

Пожалуйста, сделай следующее:

1. Выбери для сервера один из популярных языков на твой выбор (например, Node.js + Express или Python + FastAPI/Flask), который проще и быстрее всего запустить локально.
2. Напиши код этого локального веб-сервера. Он должен:
   - Слушать порт 3000.
   - Подключаться к локальной MariaDB (хост: localhost, пользователь: root, пароль: твой_пароль, база данных: roblox_db).
   - Иметь два эндпоинта:
     - POST /save-data — принимает JSON с `userId` (число), `username` (строка) и `coins` (число). Сохраняет или обновляет эти данные в таблице `player_stats`. Если игрок уже есть, его баланс (coins) обновляется.
     - GET /get-data?userId=... — принимает ID игрока и возвращает из базы JSON с его `username` и `coins`. Если игрока нет, возвращает монеты по нулям.
3. Напиши SQL-скрипт для создания таблицы `player_stats` в MariaDB с необходимыми полями (userId как PRIMARY KEY, username, coins).
4. Напиши серверный скрипт (Script) на языке Luau для Roblox Studio, который:
   - Отправляет GET-запрос при входе игрока (PlayerAdded), получает его баланс из MariaDB и записывает в Leaderstats (валюта "Coins").
   - Отправляет POST-запрос при выходе игрока (PlayerRemoving), сохраняя актуальное количество "Coins" из Leaderstats обратно в локальную MariaDB.
5. Кратко по шагам распиши, какие библиотеки нужно установить (например, через npm или pip) и как запустить этот сервер.
